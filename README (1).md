# こうのす花火大会 v33

## v33 背景花火を「本物の花火」寄りに改善
- 花火は引き続き完全な背景レイヤー（文字やカードの前には出ない）
- 背景なので発光を強化
- 丸い粒が飛ぶだけの表現を廃止
- 各火花に3段階の長い流線型トレイルを追加
  - 長い薄い残光
  - 中間の強い光跡
  - 先端直前の白熱した細い筋
- 先端は白いコア＋色付き発光で実際の火花っぽく
- 一部の火花は「hero trail」として長く太く残る
- 放射方向を均一化し、丸く開く本物の花火らしい形に調整
- 重力と空気抵抗で軌跡が少しずつ下へ垂れる
- 中心の閃光と拡大リングも強化
- スマホ縦画面の発生範囲・頻度はv32を維持
- 16時ロック、乾杯演出、準備チェック等は変更なし

既存GitHub / Vercel版は index.html の差し替えだけで更新できます。
