## スマホの打ち上げ軌跡を構造から修正
- スマホでは打ち上げ開始を固定下部ナビの上（画面下から約86px）へ変更
- 左右32px前後の夜空レーンを確保
- 上昇の前半〜中盤を夜空レーン内に保ち、頂点直前にだけ内側へ曲がる3次ベジェ軌道
- 微細な回転ブレと風ドリフトを維持し、直線的なレーザー感を抑制
- 上昇時間を約2.1〜2.9秒へ延長
- 軌跡は控えめな金色＋白芯で、背景のまま見える強さに調整
- 花火頻度はスマホ約2.2〜3.8秒ごとへ落として、一発ずつのシーケンスを見やすく

## 受賞作モチーフから着想した20パターン
大曲の花火の近年受賞作に見られるモチーフを参考に、完全再現ではなく軽量な背景表現として20種類のプリセットを用意。
滝桜、ブルーインパルス、雫、水面、秋茜、蓮池、青い結晶、花、陽炎、黄金光、朧月、青の余韻、七夕、連竜、五色竜、虹雲、オーロラ雲、錦鯉、ポッピングシャワー等の印象を、色・対称性・リング・楕円・花弁・螺旋・長い尾などで表現しています。
