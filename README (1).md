# こうのす花火大会 v40

## v40：スマホ実機で「下からの打ち上げ」が見えない問題を根本修正

### 原因
iPhone Safariでは、アドレスバー・下部ツールバーの伸縮により
`window.innerHeight` と「実際にユーザーが見ている高さ」が一致しない場合があります。

これまでの背景花火は `innerHeight` を基準に
「画面下から打ち上げる」座標を決めていたため、
実機では花火玉の開始位置が見えている画面より下に置かれ、
PCやエミュレーターでは見えるのにiPhoneでは途中からしか見えない可能性がありました。

### 修正内容
- 背景Canvasサイズを `window.visualViewport` 基準に統一
- 打ち上げ開始位置も visualViewport の下端基準
- 爆発位置・スマホ左右位置も同じ座標系へ統一
- Safariのアドレスバー伸縮時も visualViewport resize/scroll を監視してCanvasを再計算
- 打ち上げ開始位置は見えている画面の下端から約92px上
- 花火は引き続き背景レイヤー
- 軌道・20種類の花火・頻度は変更なし

既存GitHub / Vercel版は index.html の差し替えだけで更新できます。
