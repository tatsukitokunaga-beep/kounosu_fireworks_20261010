# こうのす花火大会 v35

## v35 背景花火：爆心から外へ伸びるリアルな軌跡

今回の主眼は「火花の尾」ではなく、**爆発した中心から外側へ一本ずつ伸びる光の筋**です。

### 変更内容
- 各火花が爆発中心座標を保持
- 爆心 → 現在の火花位置まで、一本の連続した放射状の光筋を描画
- 放射状の筋は3層
  - 外側の柔らかい色付き発光
  - 中央の色付きフィラメント
  - 先端へ向かう白熱した細い芯
- 爆発直後は中心から18本の短い放射スパークが広がる
- 菊・牡丹・リングは特に放射方向を揃えて、中心から外へ伸びる形を強調
- その後、重力と空気抵抗で末端が少しずつ垂れ、柳・椰子は自然に曲線化
- 既存の上昇軌跡と6種類の花火バリエーションは維持
- 花火は引き続き完全な背景レイヤー

既存GitHub / Vercel版は index.html の差し替えだけで更新できます。
