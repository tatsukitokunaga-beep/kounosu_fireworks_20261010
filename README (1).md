# こうのす花火大会 v36

## v36 背景花火：打ち上げから開花までを1本の連続モーションに変更

### 一連の流れ
1. **画面下から光る花火玉が上昇**
   - 玉そのものが白〜金色に発光
   - 長い上昇軌跡を残す
2. **頂点へ近づくほど減速**
   - 高度が上がるにつれて明確にスピードダウン
3. **頂点で玉が一瞬強く発光**
   - その場で光る「球」が見える
4. **球が破裂**
   - 白い閃光
   - 金色のショックリング
5. **中心から花火が開き始める**
   - 最初は小さくまとまり、数フレームかけて外向き速度が上がる
6. **大きく開花**
   - 爆心から外へ放射状の流線型軌跡
   - その後は重力で自然に垂れる

### その他
- 通常時は約96%の花火がこの完全な「打ち上げ→破裂→開花」シーケンス
- 2発目も約92%で同じシーケンス
- 菊・牡丹・柳・リング・椰子・キラキラの6種類は維持
- 花火は完全な背景レイヤー
- スマホ負荷対策は維持
