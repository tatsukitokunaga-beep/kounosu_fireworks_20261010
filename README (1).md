## v44：スマホの打ち上げ軌跡を「二層Canvas」に分離

- 背景花火Canvas：従来どおり z-index:0

  - 文字やカードの完全な裏
- 打ち上げ軌跡専用Canvas：スマホだけ z-index:3
  - 左右約58pxの夜空レーンだけ描画
  - 中央コンテンツ部分はCanvas上でも完全にクリップ
  - カードより前に来るため、上昇する玉と軌跡が確実に見える
  - 文字やチェック項目の上には描画されない
- 左右レーンの内側はマスクで自然にフェード
- 頂点は左右44〜52px付近に寄せ、背景側の開花へ自然に引き継ぐ
