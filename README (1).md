# たつき × あい｜花火ナイト v21

既存の GitHub / Vercel サイトに差し替えるための最終レビュー版です。

## 更新するファイル

**本番リポジトリの `index.html` だけを、この版の `index.html` に置き換えてコミットしてください。**
既存の `config.js`、Supabase のテーブル、デプロイ設定はそのまま残してください。
このZIPは更新用のため、接続情報やサービスキーを同梱していません。

HTMLはスマホへ直接ダウンロードして開くと、アプリによってコードとして表示されます。
動作確認には、デプロイ後のHTTPSのサイトURLを使ってください。フッターに「v21.0」と表示されれば新しい版です。

## 重点的に直したところ

- 動画内のカウント・手・グラス・笑いの文字・花火を、1本の動画再生時計で動かす構成へ変更
- 一時停止・読み込み待ち・シーク・再生速度の変更に追従
- 大きな数字は左右。乾杯後は複数行のタイトル、笑いの文字、継続する花火で展開
- 最後の4拍で左右からグラスを近づけ、0の瞬間に縁が接触。その後、反動・引き戻し・次の乾杯への動き
- 8拍ごとに再び乾杯。接触と「カンッ」の効果音を同じ時刻から制御
- 手首・指・グラスの透明感・液面・泡を再描画
- 乾杯表示は動画を閉じるまで継続。中央は接触の短い演出以外、なるべく映像に空ける
- 止めた動画を裏で進める擬似カウントダウンは使わない
- 花火は左右に限定し、描画対象・音声ノードが際限なく増えない設計
- 服装は上部。日本酒・プラスチックカップ／二重ステンレスタンブラーを維持。ブランケットなし
- 不要な選択肢は「今回はなし」で準備対象から外せる。酒類を全部そろえる必要なし
- 最後の「グラスに飲み物を注いだ？」だけで自動スクロール・演出開始
- 地図の全画面化は親カードから切り離して表示。退出ボタンが画面外へ出る問題を修正
- 地図操作と全画面ボタンを、下部の固定ナビに隠れにくい上側へ移動
- 地図の画像はHTMLへ埋め込み。外部の地図読込に失敗してもガイドは残る
- 15時は「到着」ではなく「出発予定」へ修正。未取得の天気を確定予報として見せない
- 共有の接続状況、失敗・ローカル保存状態を明示

## 曲に合わせる操作

1. 横向きで動画を再生します。
2. 左上の歯車から「曲と動きを合わせる」を開きます。
3. **音より動きが遅ければ「0.02秒 早く」、先走るなら「0.02秒 遅く」**を押します。
4. テンポ自体が違う場合は、サビの一定の拍に合わせて8回タップします。
5. 設定はそのスマホに保存します。ふたりの機種やBluetoothの使用状況が違う場合、各端末で調整してください。

初期テンポ158拍/分・乾杯地点10秒は従来版から引き継いだ仮の基準です。
指定動画の音声を解析して拍位置を確定した値ではありません。
YouTube IFrame APIの再生位置と状態を使う方式なので、外部プレーヤーの時刻更新や音声出力には誤差が残り得ます。
実際の曲を聴きながらの最終調整とiPhone実機での確認は、この作業環境では未実施です。

## 音量と動画

サイトからスマホ本体の音量を強制的に上げることはできません。
再生ボタンから音付き再生を試みます。止められた時は再生ボタンが再表示されます。
「♪」はグラスの効果音だけを切り替えます。曲の音はYouTube側・本体音量で調整してください。
サイト独自の演出を重ねるため、動画はサイト内で横向き再生します。
YouTube本体の画面に移ると、このサイトの乾杯演出は付いてきません。

## 共有チェック

既存の `window.SUPABASE_URL` と `window.SUPABASE_ANON_KEY` が `config.js` にある場合だけ同期を開始します。
未接続なら各スマホのローカル保存です。URLを共有しただけでは同期しません。
従来の `?room=...` とチェック項目のキーを維持しています。
「今回はなし」の状態は同じテーブルの `omit:項目キー` に保存します。
サーバー側で項目名に許可リストなどを設けている場合は、このキーも許可してください。

既存の `hanabi_checks(room,item_key,done,updated_at)` と `(room,item_key)` の一意制約を前提としています。
本番Supabaseとの接続、権限や共有者の実機同時操作は未検証です。
service_roleなどの秘密鍵はHTMLや公開リポジトリに絶対に入れないでください。
推測しにくいURLやnoindexは認証の代わりにはなりません。公開ページに機微な個人情報を入れないでください。

## 会場・地図

お気に入りの生成マップは「参考イメージ」として維持しています。
この画像は実測図ではないため、画像にGPSを投影する機能・未確認のおすすめ座標・推測ルート・直線距離からの徒歩分数は廃止しました。
実地図では、鴻巣市のポピー案内地点と、許可した場合の端末現在地を表示します。
案内地点は花火会場の正確な入口を保証しません。規制・入退場路は大会公式図と係員の案内を優先してください。
現在地はこのコードからSupabaseへ送信しません。更新停止ボタンがあります。
