# こうのす花火大会 v42

## v42：Safari / Chrome共通でスマホの「下から上がる」を見せる修正

Safariでも見えなかったため、ブラウザ固有ではなく
「上昇玉がすぐカード裏へ入る」ことを本質的な原因として修正しました。

### 打ち上げ
- スマホ左右に32〜36pxの夜空レーン
- 打ち上げ開始位置を実画面高さの約84%地点に設定
  - ブラウザUIの下に隠れる「本当の最下端」からは開始しない
- 上昇の最初の80%は左右レーン内を飛行
- 最後の20%だけ内側へカーブして開花地点へ
- 上昇時間をさらに長くして視認しやすく
- 軌跡履歴も48点に増加
- 回転ブレ・風ドリフトは残しつつ、レーンから外れすぎないよう抑制
- 光は背景として控えめなまま

### 下部ナビ
- TOP / 準備 / MAP を常に画面下部固定
- iPhone safe area対応
- Chrome / Safariの画面回転・ツールバー変化後も位置を再補正

既存の16時ロック、乾杯演出、花火バリエーション等は変更していません。
