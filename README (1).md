# こうのす花火大会 v45

## v45変更点

### 横向き動画中の下部タブ
- 乾杯演出で動画フェーズに入った瞬間、
  `TOP / 準備 / MAP` の下部ナビを完全非表示
- 横向き時は `display:none` まで適用し、動画の下側を一切隠さない
- 準備進捗の上部追従バーも動画中は非表示
- 動画を閉じたら自動で元に戻る
- iPhone Chrome / Safari の画面回転・ツールバー変化後も非表示状態を維持

### 打ち上げ軌跡
- iPhoneの「視差効果を減らす」がONでも、上昇玉を省略しないよう修正
- Reduce Motion時は負荷を落とすだけで、下から上がるシーケンスは残す

既存GitHub / Vercel版は index.html の差し替えだけで更新できます。
