# こうのす花火大会 v32

## v32 背景花火の方針修正
- 花火Canvasを完全に背景レイヤー（z-index:0）へ戻しました
- 文字・カード・チェックUIの前には花火が出ません
- スマホのカード背景を濃く戻し、可読性を優先
- 花火の発生範囲は縦画面10〜90%を維持
- 頻度はスマホ約1.05〜2.10秒ごとで、背景として十分動く程度に調整
- 2連発は約34%、3発目は約7%へ抑制
- 粒のハロー、光輪、閃光も弱めて「背景感」を優先
- Reduce Motion時も控えめな背景花火は残す
- 16時ロック、乾杯演出、準備チェックなど既存機能は変更なし

既存GitHub / Vercel版は index.html の差し替えだけで更新できます。
