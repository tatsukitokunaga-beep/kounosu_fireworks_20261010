# こうのす花火大会 v38

## v38：スマホで上昇軌跡を見せつつ、軌道を自然化

### スマホで見えなかった原因
- PCには640pxコンテンツの左右に広い夜空がある
- スマホはカードが画面幅のほとんどを使うため、背景の打ち上げ軌跡がカード裏に隠れていた

### 修正
- スマホだけ左右に約20〜24pxの「夜空レーン」を確保
- 約84%の花火は左右レーン付近で開花し、上昇もレーン内で見えやすくした
- 上昇光はv37より細く・暗くして、背景として自然な強さへ

### 軌道
- 完全な直線を廃止
- 回転由来の微妙な横ブレ
- 風による緩やかな横流れ
- 中腹で少し揺れ、発射点と頂点では揺れが小さくなる
- ブレ幅は数px〜十数px程度に抑え、蛇行しすぎない

### 頻度
- v37の落ち着いた頻度（約1.7〜3.0秒ごと）を維持
- 2連発22%、3発目3%

既存の16時ロック、乾杯演出、チェックリスト等は変更していません。
既存GitHub / Vercel版は index.html の差し替えだけで更新できます。
