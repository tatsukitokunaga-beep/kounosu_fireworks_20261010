# こうのす花火大会 v37

## v37：打ち上げ軌跡を見えるようにしつつ、頻度を少し抑制

### 打ち上げの見え方
- スマホの上昇時間を約1.8〜2.4秒へ延長
- 上昇軌跡の履歴を18点 → 34点
- スマホでは左右の画面端から上昇開始
- オレンジ残光＋金色軌跡＋白熱芯の3層
- 光る花火玉自体を大きく表示
- 頂点直前でしっかり減速
- 球 → 閃光 → 破裂 → 開花の流れは維持

### 頻度
- 通常のスマホ：およそ1.7〜3.0秒ごと
- 2連発：22%
- 3発目：3%
- ページを開いた直後の強制2連発を廃止
- 背景として賑やかだが、常に花火だらけにはならない設定

既存の16時ロック、乾杯演出、チェックリスト等は変更していません。
