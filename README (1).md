# こうのす花火大会 v31

## v31 背景花火：スマホ縦画面を実測想定で再設計
- 古い Reduce Motion CSS が `#fireworks` を完全非表示にしていた不具合を修正
- スマホ縦画面の花火発生Y座標を 10〜90% まで拡大
  - 上部 10〜30%
  - 中央 32〜66%
  - 下部 68〜90%
- 左右だけでなく中央にも定期的に出現
- スマホ通常時は約0.65〜1.30秒ごとに新規打ち上げ
- 約62%で2連発、約18%で3発目
- 初回は180msで打ち上げ、スマホではさらに380ms後に2発目
- 粒のハローを拡大し、縦長画面でも視認しやすく改善
- 花火Canvasをカードより前面に寄せ、screen合成で文字を邪魔しすぎず発光を見せる
- Reduce Motion時も完全停止せず、約1.9〜2.7秒周期の軽量表示
- 粒数上限・スマホ30fps前後の負荷制御は維持

既存機能は変更していません。

- 各打ち上げに白い閃光と拡大する光輪を追加し、「バンッ」と上がったことが縦画面でも分かるよう改善
