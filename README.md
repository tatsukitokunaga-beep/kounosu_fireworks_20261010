# こうのす花火大会 v49

## 修正点

### 花火位置
- ギャラリー内の開花中心を画面中央付近に固定
  - 横：38〜62%
  - 縦：34〜44%
- 上部タイトルと下部解説カードの間に花火が収まる配置
- ギャラリーでは花火サイズを約78%へ調整し、解説カードまで広がりにくくした
- 打ち上げ開始位置も画面高の約74%へ上げ、カードの奥深くから上がる状態を解消
- 開花直前に左右へ曲がる処理は引き続き無し

### 最下部の黒い余白
- 花火ギャラリーの高さを `visualViewport.height` と完全一致
- `height / min-height / max-height` を同じ値に固定
- ギャラリー内部を flex で構成し、解説カードを画面最下部に配置
- html / body / main / app の下余白を0へ統一
- 花火ギャラリーがサイトの本当の最終要素

iPhone Chrome / Safariのブラウザバー伸縮時も高さを再計算します。

GitHub / Vercelでは index.html の差し替えだけで更新できます。
