# こうのす花火大会 v12

GitHub Pages用です。既存リポジトリでは **index.html だけ差し替え**で更新できます。

## v12 変更点
- 乾杯演出開始後、約1.5秒後から5秒カウントダウン
- カウントダウン後に「スマホを横向きにして！」画面
- 横向きを自動検知
- 横向きになると、大きく脈動する「動画スタート」POPを表示
- POPをタップすると YouTube `Mv0Jo_P9XrA` を自動再生
- 動画は画面いっぱいに表示
- 動画を閉じると花火演出へ戻る

※ iPhone/Safariではブラウザ仕様上、音付き自動再生はユーザー操作が必要です。この版は「動画スタート」ボタンのタップを再生トリガーにしているため、その制約に合わせています。
