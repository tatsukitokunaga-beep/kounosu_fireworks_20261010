# こうのす花火大会 v17

## v17変更点
- 動画再生中のカウントダウンを右上カード方式から廃止
- 横画面の動画左右にできる黒帯を「左右連動演出レーン」として使用
- 10→0を左右同時表示。左は左外側、右は右外側から数字が飛び込む
- カウントのたびに左右レーンが同期して発光
- 0の後は左「乾杯〜！」／右「🎉🥂」へ切替
- 「乾杯〜！」演出は動画を閉じるまで左右で発光・星・小型花火を継続
- 中央のYouTube動画にはカウント・乾杯カードを重ねない
- 閉じるボタンは左右演出を邪魔しないよう動画上部中央へ移動
- スマホ負荷を抑えるため左右花火の大部分はCSSアニメーション

既存のGitHub/Vercel版は `index.html` の差し替えだけで更新できます。
