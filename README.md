# こうのす花火大会 v20

## 曲のビート同期を追加
指定動画は「新宝島」で、BPM 158 / 4拍子を前提に演出を同期しています。

### カウントダウン中
- 数字自体は 10→0 の秒カウント
- その数字・左右背景が曲の四分音符ごと（約0.38秒）に脈動
- 4拍ごとに強いアクセント
- 左右の発光を交互に振ってリズム感を強化

### カウント0以降
- サビ開始を 10.0秒地点としてビート原点化
- タイトル・星・グラスが毎拍リズムを刻む
- 2拍ごとに 😂ｗ / 🤣 / 爆笑😂 / ✨ などが左右から飛び出す
- 4拍ごとに左右の花火・光を強く発火
- 8拍周期で手とグラスが再接近し、ビート位置で「カンッ」と乾杯
- YouTubeの実再生時間から毎フレーム拍位置を算出するため、バッファリング時もタイマーだけ先走りにくい
- 動画を閉じるまで演出継続

既存GitHub/Vercel版は `index.html` の差し替えだけで更新できます。
