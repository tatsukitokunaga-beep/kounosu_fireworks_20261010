# こうのす花火大会 v50

## 最終安定化
- iPhone最下部でスクロールを押し続けた際のガタつきを修正
- 原因だった visualViewport.scroll ごとの高さ書き換えを完全廃止
- 花火ギャラリーは変動しない 100lvh で固定
- ギャラリーモード切替に広いヒステリシスを追加し、弾性スクロールでON/OFFを反復しない
- 下部ナビはレイアウトを変えず、透明・移動だけで非表示
- overscroll-behavior-y:none を追加

## 花火のグレードアップ
- ギャラリー花火の光線数を約1.32〜1.46倍へ
- 明るい主要光線を増加
- 軌跡・発光の彩度と輝度を強化
- 開花直後の放射スパークを18本から28本へ
- ギャラリー中の粒子上限を引き上げつつ、1発ずつの間隔は維持

index.html の差し替えだけで更新できます。
